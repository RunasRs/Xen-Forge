# Sécurité

## Versions prises en charge

Seule la dernière version publiée reçoit des correctifs de sécurité.

## Signaler une vulnérabilité

Ne signalez jamais une vulnérabilité dans une issue publique.

Utilisez le signalement privé de GitHub : onglet [Security](https://github.com/RunasRs/Xen-Forge/security) du dépôt, puis **Report a vulnerability**. Le signalement n'est visible que par vous et par le mainteneur.

Indiquez si possible :

- la version de Xen Forge concernée ;
- le composant touché (application, Packer, OpenTofu, Ansible, base de données) ;
- les étapes pour reproduire le problème ;
- l'impact estimé.

## Traitement

Le signalement est examiné, puis la vulnérabilité est corrigée dans une nouvelle version. L'avis de sécurité est publié une fois le correctif disponible.

Merci de ne pas divulguer la vulnérabilité avant la publication du correctif.
